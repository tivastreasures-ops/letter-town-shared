It's fine and useful to keep '_PLACEHOLDER' in source FILENAMES and 'status: PLACEHOLDER' in manifests, developer notes, debug UI (disabled by default) and code comments.

IMPORTANT: Several preexisting generated images have 'PLACEHOLDER' rendered into the actual PIXELS. Renaming these files is NOT a cleanup.
